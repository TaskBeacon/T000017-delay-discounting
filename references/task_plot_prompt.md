# Task Plot Prompt

Create a clean scientific task-flow timeline on a white background with a blank top header band reserved for later overlay. Do not draw any title, subtitle, logo, watermark, people, device, lab room, or decorative scene.

Use three horizontal rows:

1. Small magnitude
2. Medium magnitude
3. Large magnitude

For every row, draw the same left-to-right sequence with arrows:

1. Cue
   - Screen: fixation cross.
   - Timing: 600 ms.
   - Response label: no response.
2. Anticipation
   - Screen: fixation cross.
   - Timing: 200 ms.
   - Response label: no response.
3. Choice
   - Screen: two side-by-side monetary options, one labeled smaller-sooner and one labeled larger-later.
   - Add concise example text such as "SS: 25 today" and "LL: 30 in 14 days".
   - Timing: up to 6000 ms.
   - Response label: press F(left) / J(right).
   - Include a small note that LL side is counterbalanced.
4. Confirm
   - Screen: both options remain visible with a highlight around the selected side.
   - Timing: 300 ms.
   - Response label: only if response.
5. Feedback
   - Screen: show "choice feedback" and "timeout feedback" as alternatives.
   - Timing: 500 ms.
   - Response label: no response.
6. ITI
   - Screen: fixation cross.
   - Timing: 500 ms.
   - Response label: no response.

Keep all text readable. Use compact boxes, clear arrows, and consistent row spacing.
