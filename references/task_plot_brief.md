# Task Plot Brief

## Task

- Title: Delay Discounting Task
- Construct: delay discounting / intertemporal choice
- Paradigm: MCQ-27 style monetary choice between smaller-sooner and larger-later options.

## Rows

- Small magnitude
- Medium magnitude
- Large magnitude

## Trial Timeline

1. Cue: 600 ms fixation, no response.
2. Anticipation: 200 ms fixation, no response.
3. Choice: 6000 ms response window. Show two monetary options, smaller-sooner and larger-later, with side assignment counterbalanced. Press F for the left option or J for the right option.
4. Choice confirmation: 300 ms only if a response was made. Show both options and highlight the selected side.
5. Feedback: 500 ms. Show choice feedback for valid responses or timeout feedback for missed trials.
6. ITI: 500 ms fixation, no response.

## Notes

- Magnitude labels are generated from the deterministic MCQ item pool and are not shown before the choice screen.
- The larger-later option can appear on either side; the graphic should label the choice as SS vs LL without implying a fixed side.
